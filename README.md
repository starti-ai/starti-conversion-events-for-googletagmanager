# Starti Conversion Events Pixel for Google Tag Manager

This repository contains the Starti web tag template for Google Tag Manager Community Template Gallery submission.

The template loads the hosted Starti Pixel SDK, initializes it with `adv_id` and `pixel_id`, and sends browser events using the Starti v1.0.0 compact web event schema.

## Repository Contents

- `template.tpl`: GTM web tag template source
- `metadata.yaml`: Community Template Gallery metadata
- `LICENSE`: repository license

SDK source and minified release files are maintained outside this Google review repository. The template references the hosted versioned SDK file:

```text
https://piexl.oss-cn-beijing.aliyuncs.com/starti-pixel-v1.0.0.min.js
```

## Runtime Model

- Website installs the standard Google Tag Manager snippet.
- GTM loads this Starti template.
- The template creates `startiQueue`, injects `https://piexl.oss-cn-beijing.aliyuncs.com/starti-pixel-v1.0.0.min.js`, queues `starti('init', ...)`, then queues `starti('track', ...)`.
- The SDK generates `su`, optional `sid`, event IDs, event time, and sends the final compact payload.
- The template does not generate `su` or `sid`.
- The template does not expose Collector endpoint configuration to customers.

## SDK Payload

The SDK sends one event per request. The browser payload uses compact field names:

```json
{
  "v": "v1.0.0",
  "aid": "adv_001",
  "pxid": "px_001",
  "eid": "evt_xxx",
  "en": "purchase",
  "et": 1710000000000,
  "su": "st_xxx",
  "sid": "sess_xxx",
  "pu": "https://example.com/checkout/success",
  "oid": "ORDER-1001",
  "val": "129.99",
  "cur": "USD"
}
```

## Identity Behavior

- `su` is generated by the SDK and stored in `localStorage` under `_starti_st_uid`.
- If `localStorage` is unavailable, the SDK uses an in-memory `su`.
- `sid` is generated by the SDK and stored in the `_starti_sid` cookie.
- `sid` refreshes after 30 minutes of inactivity.
- If cookies are unavailable or session tracking is disabled, `sid` is omitted.

## Sending Behavior

The SDK sends events in this order:

1. `navigator.sendBeacon` with POST JSON
2. `fetch` with `keepalive` and POST JSON
3. Image pixel GET fallback with key fields only

The SDK does not send IP, User-Agent, UTM, or Google/Facebook traffic classification fields. Those are resolved by the Collector or downstream attribution layer.

## Direct SDK Usage

Customers who do not use GTM can install the SDK directly:

```html
<script>
  window.startiQueue = window.startiQueue || [];
  window.starti = window.starti || function () {
    window.startiQueue.push(arguments);
  };

  starti('init', {
    adv_id: 'adv_001',
    pixel_id: 'px_001'
  });

  starti('track', 'page_view');
</script>
<script async src="https://piexl.oss-cn-beijing.aliyuncs.com/starti-pixel-v1.0.0.min.js"></script>
```
